# ICT DOJO · 交易学习练习复盘平台

一个基于 **ICT（Inner Circle Trader）交易方法论** 的浏览器训练平台：**学习核心概念 → 图表标记练习 → K线逐根回放复盘 → 交易日志沉淀**，形成完整的训练闭环。

> **数据说明**：平台内所有行情均由算法实时生成的**合成数据**，仅用于教学与练习，不构成任何投资建议。

## 在线访问

**[https://hdhaidong.github.io/ict-dojo/](https://hdhaidong.github.io/ict-dojo/)**

由 GitHub Pages 托管，浏览器直接打开即用。学习进度自动保存在浏览器 localStorage 中。

## 四大功能模块

### 1. 课程学习（8 节）

覆盖 ICT 体系核心概念，每课配有**算法实时检测并标注的图例**与随堂测验：

| 课 | 主题 | 图例标注 |
|---|---|---|
| 01 | 市场结构与 BOS / CHoCH | 摆动点 HH/HL/LH/LL、结构突破线 |
| 02 | 流动性与扫荡 | BSL/SSL 流动性池、扫荡K线 |
| 03 | 公允价值缺口 FVG | 看涨/看跌缺口色块 |
| 04 | 订单块 OB | 看涨/看跌订单块区域 |
| 05 | Killzone 时间窗 | 伦敦/纽约时段底纹 |
| 06 | 溢价与折价 | EQ 均衡价、Premium/Discount 分区 |
| 07 | SMT 背离 | EURUSD 与 DXY 双图对照 |
| 08 | 综合入场模型（2022 Model） | ①扫荡→②CHoCH→③FVG→④目标 全流程 |

测验达到 2/3 正确即计入完成进度。

### 2. 图表练习

算法每次生成**全新行情**，在图上**点击作答**，即时反馈并高亮正确答案：

- FVG 识别（看涨 / 看跌）
- 订单块识别（看涨 / 看跌）
- 流动性识别（BSL / SSL）
- BOS / CHoCH 事件定位
- 流动性扫荡定位
- 概念测验（8 节课题库混合 10 题）

每轮 5 题，自动统计各类练习的正确率。

### 3. K线回放复盘

- 逐根推进行情（空格播放/暂停，←/→ 单根，支持 +10 跳跃）
- 任意时点做出**做多 / 做空 / 平仓**决策，图表自动标记进出场
- 结束后自动结算：交易笔数、胜率、总盈亏（点）、最大回撤、评级
- 权益曲线可视化，可叠加 **ICT 参考标记**（FVG + 结构事件）对照自己的判断
- 打标签（流动性扫荡 / 2022模型 / 纪律良好 等）+ 复盘笔记

### 4. 交易日志

所有复盘记录自动归档：时间、标的、交易数、胜率、盈亏、回撤、标签与笔记，支持删除，并汇总累计统计。

## 快速上手

1. 打开在线地址（或下载 `index.html` 双击打开，**零依赖、零构建、离线可用**）
2. 先到「课程学习」过一遍 8 节课
3. 到「图表练习」做几轮标记训练，检验概念是否真正掌握
4. 每天到「K线回放复盘」做 1~2 局回放训练，写下复盘笔记
5. 「训练总览」跟踪课程进度、练习正确率、连续训练天数

## 技术说明

- **单文件 HTML 应用**：无框架、无构建、无外部依赖，任何现代浏览器直接运行
- **自研 Canvas K线引擎**：支持滚轮缩放、拖动平移、十字线、标注层（区域/水平线/标签/交易标记）
- **算法合成行情**：基于「趋势 → 整理 → 操纵扫荡」状态机的行情生成器，天然产生 FVG、订单块、等高低点、流动性扫荡等教学特征
- **ICT 特征检测器**：摆动结构（BOS/CHoCH）、公允价值缺口、订单块、流动性池与扫荡的算法检测，课程图例与练习判分均由同一套检测器驱动，保证标注与数据一致
- **localStorage 进度持久化**：课程进度、练习统计、复盘日志、连续训练天数全部本地保存
